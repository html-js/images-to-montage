# Changelog

This file records what changed in each release. It follows the
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) style, and version
numbers follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-11-07

First public release. The tool ships as a single dependency-free page that
combines many images into one montage. Pictures arrive by drag and drop,
paste, the file and folder pickers, or typed paths and URLs, and dropped
folders are read with their subfolders in natural name order.

There are five layouts. A grid fits each picture by contain, cover or
stretch, and the others are justified rows, masonry columns, a single row
and a single column. Sizes can
follow the source pictures so nothing is shrunk, or be set by hand. Gaps,
outer padding, rounded corners, borders and background color are adjustable,
and captions can print the index or file name as a band or a corner badge.
The result downloads as PNG, JPEG or WebP at any scale the browser's canvas
allows, or goes to the clipboard as PNG.

For publishing, the page gained a title and a search description, and its
font stacks and code comments now name only generic system families and
engines.
